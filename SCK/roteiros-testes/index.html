Catálogo de Roteiros de Testes DOC (E2E / QA)

Visão Geral da Automação de Documentação

Seção intitulada “Visão Geral da Automação de Documentação”

Seguindo o modelo de Documentação Viva (Docs as Code) validado no projeto FlowBusiness, todas as capturas visuais e demonstrações deste portal são geradas a partir de testes automatizados ponta a ponta (E2E) marcados com o prefixo DOC_.

Catálogo de Cenários e Identificadores de Ativos

Seção intitulada “Catálogo de Cenários e Identificadores de Ativos”

Abaixo estão os roteiros oficiais dos 8 módulos da V1:

Módulo ID do Ativo (Asset ID) Arquivo de Destino Ações do Teste E2E
1. Início DOC_INICIO_TELA_STANDBY_0001 assets/gifs/INICIO/DOC_INICIO_TELA_STANDBY_0001.gif 1. Aguarda tela de repouso por 3s.
2. Exibe carrossel de mídia.
3. Toca no centro da tela.
4. Abre tela inicial de venda.
2. Cliente DOC_CLIENTE_IDENTIFICACAO_CPF_0001 assets/gifs/CLIENTE/DOC_CLIENTE_IDENTIFICACAO_CPF_0001.gif 1. Toca no botão “Digitar CPF”.
2. Digita no teclado virtual o CPF mock: "123.456.789-00".
3. Toca em “Confirmar”.
4. Valida retorno positivo de identificação.
3. Carrinho DOC_CARRINHO_LEITOR_BIPAGEM_0001 assets/gifs/CARRINHO/DOC_CARRINHO_LEITOR_BIPAGEM_0001.gif 1. Dispara evento de leitor óptico com EAN mock: "7891234567890".
2. Item inserido no carrinho.
3. Atualiza totalizador.
3. Carrinho DOC_CARRINHO_DIGITACAO_MANUAL_0001 assets/gifs/CARRINHO/DOC_CARRINHO_DIGITACAO_MANUAL_0001.gif 1. Toca no botão “Digitar Código”.
2. Digita o código numérico "7890001122".
3. Toca em “Adicionar ao Carrinho”.
3. Carrinho DOC_CARRINHO_LEITURA_RFID_0001 assets/gifs/CARRINHO/DOC_CARRINHO_LEITURA_RFID_0001.gif 1. Simula recepção de 3 tags EPC no cesto RFID.
2. Sistema agrupa e exibe os 3 produtos de uma vez no carrinho.
4. Descontos DOC_DESCONTO_PROMO_STOREX_0001 assets/gifs/DESCONTO/DOC_DESCONTO_PROMO_STOREX_0001.gif 1. Bipa item participante da promoção “Leve 3 Pague 2”.
2. Ao atingir o 3º item, a tag PROMOÇÃO é exibida.
3. Total de desconto atualizado.
5. Pagamentos DOC_PAGAMENTO_CARTAO_TEF_0001 assets/gifs/PAGAMENTO/DOC_PAGAMENTO_CARTAO_TEF_0001.gif 1. Toca em “Cartão de Crédito”.
2. Simula resposta de aprovação do Pinpad SiTef.
3. Confirmação de pagamento na tela.
5. Pagamentos DOC_PAGAMENTO_PIX_QRCODE_0001 assets/gifs/PAGAMENTO/DOC_PAGAMENTO_PIX_QRCODE_0001.gif 1. Seleciona “Pix”.
2. Exibe QR Code dinâmico.
3. Simula notificação bancária de crédito.
4. Transição automática de sucesso.
6. Cupom DOC_CUPOM_IMPRESSAO_TERMICA_0001 assets/gifs/CUPOM/DOC_CUPOM_IMPRESSAO_TERMICA_0001.gif 1. Venda finalizada com sucesso.
2. Disparo de comando de corte na impressora.
3. Exibição da mensagem para retirar o cupom.
6. Cupom DOC_CUPOM_EMAIL_SMTP_FINALIZACAO_0001 assets/gifs/CUPOM/DOC_CUPOM_EMAIL_SMTP_FINALIZACAO_0001.gif 1. Na tela final, toca em “Enviar por E-mail”.
2. Digita no teclado virtual: "cliente@teste.com".
3. Toca em “Enviar”.
4. Mensagem de envio via SMTP concluído.
7. NPS DOC_SURVEY_NPS_AVALIACAO_0001 assets/gifs/SURVEY/DOC_SURVEY_NPS_AVALIACAO_0001.gif 1. Após aviso fiscal, tela de NPS é exibida.
2. Toca na nota “10” (verde).
3. Dispara payload assíncrono para o Formbricks.
4. Exibe tela de agradecimento.
8. Operador DOC_OPERADOR_CANCELAR_ITEM_0001 assets/gifs/OPERADOR/DOC_OPERADOR_CANCELAR_ITEM_0001.gif 1. Toca na lixeira do item 2.
2. Abre modal de autenticação de fiscal.
3. Digita credencial de operador "999".
4. Item estornado com sucesso.
8. Operador DOC_OPERADOR_CANCELAR_VENDA_0001 assets/gifs/OPERADOR/DOC_OPERADOR_CANCELAR_VENDA_0001.gif 1. Abre menu superior.
2. Seleciona “Cancelar Venda”.
3. Fiscal confirma motivo.
4. Totem retorna ao início.
8. Operador DOC_OPERADOR_MENU_FISCAL_0001 assets/gifs/OPERADOR/DOC_OPERADOR_MENU_FISCAL_0001.gif 1. Toque longo no logo administrativo.
2. Login de gerente.
3. Toca em “Abrir Gaveta” e “Leitura X”.
