7. Pesquisa de Satisfação (NPS)

Visão Geral da Funcionalidade

Seção intitulada “Visão Geral da Funcionalidade”

A Pesquisa NPS (Net Promoter Score) permite que o lojista meça em tempo real o nível de satisfação do consumidor com o atendimento autônomo no totem.

Ao concluir uma venda, o cliente é convidado a responder à pergunta:

“Em uma escala de 0 a 10, o quanto você recomendaria esta experiência de compra?”

O resultado é gravado na base da transação e despachado de forma assíncrona para a plataforma Formbricks, permitindo consolidar dashboards de experiência do cliente, identificar totens com problemas operacionais e acompanhar a lealdade da marca.

Sistemas Envolvidos & Versões Mínimas

Seção intitulada “Sistemas Envolvidos & Versões Mínimas”

Para que a funcionalidade possa ser ativada na loja, os sistemas devem estar nas seguintes versões mínimas homologadas:

Sistema Versão Mínima Homologada
Linx Self-Checkout 3.39.0 ou superior
Storex Cloud 4.4.0 ou superior
Serviço de Pesquisas Provedor Formbricks integrado

Fluxo Operacional no Totem

Seção intitulada “Fluxo Operacional no Totem”

A exibição da pesquisa respeita a ordem natural de saída do cliente do checkout:

  1. Conclusão Fiscal: O pagamento é aprovado, o cupom fiscal é emitido/impresso e as mensagens orientativas de retirada de sacolas são apresentadas.
  2. Exibição da Pergunta: A tela de NPS surge com a pergunta central e uma barra com botões de 0 a 10:
    • 0 a 6 (Detratores): Tons de vermelho/laranja.
    • 7 e 8 (Neutros): Tons de amarelo.
    • 9 e 10 (Promotores): Tons de verde.
  3. Seleção ou Pulo:
    • Se o cliente tocar em uma nota, a opção é destacada e o voto é registrado.
    • Se preferir não avaliar, o botão “Pular” encerra a tela imediatamente.
  4. Tela de Confirmação: Uma mensagem de agradecimento é exibida por 3 segundos e o totem retorna à tela inicial de repouso (Standby).

Parâmetros Oficiais de Configuração

Seção intitulada “Parâmetros Oficiais de Configuração”

Para habilitar a Pesquisa NPS no Self-Checkout, devem ser adicionadas as propriedades no servidor de configurações de retaguarda:

Grupo: SELF-CHECKOUT - GLOBAL / Categoria: SURVEY

Seção intitulada “Grupo: SELF-CHECKOUT - GLOBAL / Categoria: SURVEY”
Identificador do Parâmetro Tipo Default Descrição
self-checkout.survey.enabled Booleano false Habilita ou desabilita a exibição da tela de pesquisa no totem.
self-checkout.survey.survey-id Texto - Identificador único da pesquisa criada dentro do Formbricks.
self-checkout.survey.question-id Texto - Identificador da pergunta de recomendação no Formbricks.

Grupo: LINX-WEBSERVICES - GLOBAL / Categoria: SURVEY

Seção intitulada “Grupo: LINX-WEBSERVICES - GLOBAL / Categoria: SURVEY”
Identificador do Parâmetro Tipo Exemplo Descrição
survey.formbricks.api-key Senha fb_live_... Chave de API de autenticação no serviço Formbricks.
survey.formbricks.url Texto https://api.formbricks.com URL base do endpoint da API do Formbricks.
legacy.default-providers Texto SURVEY=FORMBRICKS; Provedor de pesquisa ativo (adicionar preservando os demais existentes).

Perguntas Frequentes (FAQ)

Seção intitulada “Perguntas Frequentes (FAQ)”

O sistema tem pesquisa NPS? Se sim, como habilita?

Seção intitulada “O sistema tem pesquisa NPS? Se sim, como habilita?”

Sim, possui nativamente a partir da versão 3.39.0.
Para habilitar:

  1. Obtenha a API Key, o survey-id e o question-id na conta Formbricks da rede.
  2. No retaguarda, cadastre as chaves nos grupos SELF-CHECKOUT - GLOBAL e LINX-WEBSERVICES - GLOBAL descritos na tabela acima.
  3. Ative o parâmetro self-checkout.survey.enabled = true.
  4. Reinicie o totem para carregar as novas flags.

Se o totem estiver offline ou a API do Formbricks falhar, a venda é prejudicada?

Seção intitulada “Se o totem estiver offline ou a API do Formbricks falhar, a venda é prejudicada?”

Não. O envio das respostas do NPS é totalmente assíncrono e desacoplado. A venda fiscal já foi finalizada antes da pesquisa abrir. Caso ocorra timeout de rede, a resposta é armazenada localmente em fila ou descartada sem jamais travar o fluxo de compras do próximo cliente.

O cliente é obrigado a responder para sair da tela?

Seção intitulada “O cliente é obrigado a responder para sair da tela?”

Não. O botão “Pular” fica sempre disponível e visível. Além disso, existe um timeout de inatividade configurado: se o cliente for embora sem tocar na tela, após alguns segundos o totem limpa a sessão e volta para o descanso automaticamente.
